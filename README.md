# Journal Select Skill

## 是什么

帮助中文和英文论文作者筛选期刊、核查投稿风险，并给出匹配理由与投稿顺序。

## 如何安装

1. 下载本仓库，将 `skills/journal-select` 文件夹复制到 `$CODEX_HOME/skills/`；未设置时使用 `~/.codex/skills/`。
2. 确认入口为 `~/.codex/skills/journal-select/SKILL.md`（自定义目录时替换前缀），重新打开 Codex 会话。

需配合网页检索工具核验最新信息；无法访问的数据会标为待核实。

## 能解决哪些问题

- 核对实际收录类别，避免把 ESCI 误认为 SCIE/SSCI。
- 查询 On Hold、JCR Suppressed、中科院预警及新锐 Under Review 等动态状态。
- 匹配论文研究方向、方法和期刊读者，避免只看影响因子。
- 区分预警、疑似掠夺性与假刊，核对官方投稿入口。
- 检查自引指标及其统计口径，提示需要进一步核查的风险。
- 核对 AI 使用、图表、数据与伦理等投稿要求。
- 结合审稿、修回和转投安排时间，区分接收、上线与检索。

## 怎么用

提供题目、摘要及发表要求，然后输入：

```text
使用 $journal-select，根据我的论文和发表要求推荐 3–5 本期刊，核对收录、风险、费用及投稿政策，给出投稿顺序和时间建议。
```

可补充目标收录库、预算、截止日期和单位认定要求。

## 输出结构

1. **候选总览**：收录、分区、匹配理由与费用。
2. **风险核查**：动态状态、自引、身份及历史记录。
3. **投稿顺序**：推荐理由、拒稿风险和适用条件。
4. **合规待办**：AI、图表、数据及伦理材料。
5. **时间计划**：审稿周期、修回与转投安排。
6. **证据来源**：链接、版本、核验日期和待确认项。

## 维护与验证

当前版本：**0.2.0**。政策与期刊状态在使用时查询，正式投稿前应再次复核。

更新后检查文件链接，并按[验收案例](skills/journal-select/references/acceptance-cases.md)验证行为；可使用 skill-creator 的 `quick_validate.py` 检查结构。结构校验不替代真实选刊测试，推荐也不保证录用。
