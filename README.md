# Journal Select Skill

面向中文与英文论文的可复用选刊 Skill。将论文匹配、官方证据与作者硬条件结合，输出候选比较和投稿顺序。

## 设计

**论文画像 → 候选发现 → 身份与实际收录核验 → 动态风险 → 稿件匹配 → 合规与时间权衡 → 投稿顺序。**

- 不把影响因子等同于 SCIE/SSCI 收录，不把 JCR 分区与其他分区混用。
- 动态信息记录来源、核验日期和适用年份；关键未知项单独列出。
- 不预存易过期的期刊白名单、费用表或 AI 政策结论。
- 不预测录用率，不自动投稿、付费或向第三方上传研究材料。
- 支持探索候选、个性化推荐、指定期刊比较和投稿前复核。

## v0.2.0：针对七类选刊问题

| 问题 | Skill 的具体处理 |
|---|---|
| 有 IF/Q1 就以为是 SCI/SSCI | 独立核对索引、覆盖状态、指标年份和单位规则 |
| 旧截图掩盖动态风险 | 分列 WoS On Hold、剔除、JCR Suppressed、中科院预警、新锐 Under Review；记录版本与检查覆盖率 |
| 只看指标，不看稿件方向 | 用 scope 和近期相近论文解释问题、方法、贡献与读者匹配 |
| 预警、掠夺性、假刊混为一谈 | 区分评价状态、经营疑点与冒用身份，核对官方投稿域名 |
| 忽视期刊自引 | 记录口径、年份、趋势及数据缺口，不设“超阈值必剔除”结论 |
| 忽视 AI、图表和数据规范 | 将实际使用场景映射到现行条款、披露位置及材料待办 |
| 低估审稿周期 | 分阶段记录时长，明确截止状态，考虑修回与拒稿转投情景 |

不会把“未查到”写成“无风险”，不会把后续名单未出现写成“官方解除”，不会把 ESCI 定性为劣质，也不使用“保底刊”承诺。

没有实时风险库或付费数据库连接时，Skill 会披露查询缺口。它不会假装调用不存在的数据库，也不会默认开启后台监测。

## 安装到 Codex

把 `skills/journal-select` 整个文件夹复制到自己的 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时通常为 `~/.codex/skills/`。安装后的入口应是 `skills/journal-select/SKILL.md`，不要再多嵌套一层仓库目录。重新打开会话使环境发现新 Skill。

仓库地址：https://github.com/AphroditeYu/Journal-select-skill

该 Skill 使用可用的网页检索工具；没有联网能力时只能提供暂定建议和待核实清单。数据库订阅、付费访问及机构目录不会由 Skill 自动获得。无需配置 API 密钥或运行专用脚本。

## 使用示例

```text
使用 $journal-select 辅助选刊。
题目：我的论文题目
摘要：我的论文摘要
文章类型：实证研究
硬条件：必须为 SSCI；学校适用目录另附
预算：总费用不超过 10000 元人民币
期限：希望六个月内接收（请判断风险，不承诺）
偏好：主题匹配优先，其次时间
请给出 3–5 本候选，附官方来源、核验日期和投稿顺序。
```

也可以说：`使用 $journal-select 比较我列出的三本期刊，重点核对收录、费用和 AI 使用要求。`

```text
使用 $journal-select 对我的候选刊做投稿前复核。
请分别核对 WoS On Hold、JCR Suppressed、中科院预警和新锐 Under Review，
保留历史记录并说明本次查询覆盖了哪些来源。
我的论文用了 AI 辅助梳理文献和绘制流程图，请核对披露与图像要求。
截止日期为我提供的日期，届时必须完成数据库检索，请单列时间风险。
```

## 报告结构

1. 候选总览：期刊链接、ISSN、实际索引、指标年份、分区、匹配与费用。
2. 风险矩阵：各来源独立状态、身份、自引、历史变化与证据覆盖。
3. 投稿顺序：理由、拒稿风险、适用前提；不机械按 IF 排名。
4. 合规待办：AI、图表、数据、伦理等与本稿有关的准备动作。
5. 时间计划：阶段指标、截止状态、转投方案与明确标注的假设。
6. 证据台账：来源、版本、核验时间及未知项。

默认输出 Markdown。用户要求 HTML/PDF 时，可借助所在环境的文件生成能力制作可打印报告；这些格式能力不由本 Skill 自带。示例截图只用于布局启发，不作为任何期刊事实的证据。

不要在 GitHub issue 或公开提交中粘贴未发表全文、原始数据、个人信息或登录凭据。个人选刊报告应放在仓库之外。

## 维护与验证

版本：0.2.0。入口和 UI 元数据保持一致；更新时检查内部链接，并用 `references/acceptance-cases.md` 中的场景验证行为。若环境提供 skill-creator，可运行其 `scripts/quick_validate.py` 检查 Skill 结构。

结构校验不证明推荐质量。真实选刊仍需当前官方信息与用户所在单位要求。仓库不包含真实用户稿件、数据库导出内容或预置期刊推荐结论。

当前未指定开源许可证；仓库所有者可按实际意愿另行选择并添加 LICENSE。
