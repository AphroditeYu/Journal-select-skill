# 动态风险、身份与自引核查

## 1. 先确定期刊身份

记录正式刊名、pISSN/eISSN、出版商、官方期刊主页及从主页进入的投稿入口。更名、转社、续刊或不同语种版本须核对关联记录；不要只按刊名模糊匹配。

对疑似假刊/套刊，将用户给出的域名与出版商、ISSN/数据库记录及真实近期论文 DOI 落地页交叉核对。ISSN 和 DOI 可被冒用，单一标识不能证明网站真实。Editorial Manager 等第三方投稿域名本身不异常，必须核对是否由官方主页链接。

证据冲突时写“身份待核实，暂缓通过此入口提交”，不上传稿件、不支付费用。若有明确冒用证据，排除的是该入口，并继续判断真实期刊，不自动污名化被冒用的期刊。

## 2. 不同状态必须分列

| 检查项 | 表达与处理 |
|---|---|
| 实际收录 | 从数据库核验 SCIE、SSCI、AHCI、ESCI 或其他类别及覆盖年份。不能由 IF、Q1、分区或出版社倒推出索引类别 |
| WoS On Hold | 核验 MJL 当前标识；表示重新评估期间暂停处理新增内容的索引，不等于已剔除或已认定不端。依赖 WoS 检索的作者，默认暂缓将其列为可立即投稿的首选 |
| WoS Editorial De-listing | 核对官方月度变化和覆盖截止，不能把检索无结果直接当成剔除，也不能承诺历史文章均保留或均被删除 |
| JCR Suppressed | 按实际数据年/发布年核对指标暂停发布；与 WoS 覆盖是不同维度。不能写成“已被 WoS 剔除” |
| 中科院国际期刊预警 | 记录发布主体、名单年份、命中原因及用户单位的处理规则 |
| 新锐 Under Review | 独立记录新锐名单、版本、原因；不得改称中科院预警，也不得把 Under Review 等同于 WoS On Hold |
| 单位限制 | 独立核对适用目录、年级/职称范围及认定时点；名单未收录不等于单位认可 |

对每项使用事实状态：**当前命中 / 历史命中 / 已查来源未见记录 / 未核实 / 来源冲突 / 不适用**。可另记“官方明确解除”，但不能仅由新名单未出现就推断正式解除或自动恢复单位认可。

“当前命中”与“未见记录”都须来自适用来源的实际检索。网页无法打开、名单范围不明、只有搜索摘要，必须标未核实或间接线索。JCR 数据年、发布年与查询 URL 中的年份可能不同，以页面正文为准。

## 3. 证据覆盖与时效

每次正式推荐重查动态状态，保存核验时间（含时区）、来源更新时间/名单版本和匹配的 ISSN。最终投稿前再次查；报告只代表查询时可访问的信息，不保证之后没有变化。

有旧报告时，逐项比较“旧证据 → 新证据 → 变化 → 对投稿决定的影响”。历史记录保留，不能被最新未命中覆盖。

第三方风险库：必须实际可用且记录维护者、数据版本、包含的来源、匹配方式。没有此工具就直接用官方来源，不能虚构 `journal-risk` 或“已调用风险数据库”。第三方未命中不能替代官方检查；来源不完整时报告覆盖缺口。

报告覆盖率用 **已完成适用检查项数 / 应检查项数**，同时报“完成全部适用检查的期刊数 / 候选数”。不适用说明原因并排除分母。历史核查与当前核查分开；状态可以重叠，不把风险种类计数相加当期刊总数。

推荐摘要措辞：“在已核实的来源和版本中未见当前记录；另有若干项未核实”，不写“全部无风险”。

## 4. 预警、掠夺性与假刊的区别

- 预警/评估中：某机构的风险提示或评估状态，解释适用范围，不直接定性为掠夺性。
- 疑似掠夺性经营：结合同行评议、编辑身份、费用透明度、误导性指标和权威调查等具体证据。若无充分证据，描述疑点，不下“掠夺性期刊”定论。
- 假刊/劫持网站/套用刊号：身份真实性问题，核对目标域名与官方入口。正规期刊也可能被冒用。
- ESCI、OA、新刊、快速处理、发文量大或未加入某组织均不能单独证明掠夺性；也不能说发表成果“必然无效”，认定取决于用户规则。

## 5. 自引指标

优先取同年 JCR 的原始数据或官方报告，清楚区分：
- JIF 分子内期刊自引占比 = 同刊对 JIF 计量窗口论文的有效引用 / 同口径 JIF 分子引用总数。
- 全年份被引中的期刊自引占比：不是同一窗口，不能与前项混用。
- JIF 排除自引前后的变化：若使用 `(JIF − 排除自引的 JIF) / JIF`，标为基于同年数值的近似影响比例，注意四舍五入；不得命名为通用自引率。JIF 为零/缺失时不计算。

附数据年、分子/分母口径和出处。有条件时比较多年度趋势、同学科背景以及去除自引后的排名变化；缺数据写未知。不要用 Crossref 不完整引用记录伪装 JCR 官方自引率。

没有统一的“超过 20%/30% 必剔除”规则可用于本 Skill；用户自设筛查阈值须标为个人风险偏好。自引异常是进一步核查信号，不能预测必然 On Hold、剔除或录用受阻。自引低也不能排除互引操纵或其他风险。

## 6. 决策标签（本 Skill 的建议，不是官方评级）

- **排除**：明确不满足硬条件，或已证实使用冒用入口。
- **暂缓**：身份冲突、当前动态风险影响关键目标，或关键证据不足，需要先解决。
- **条件候选**：可解释的历史/现行提示或待确认条件，明确触发条件，不计为无条件首选。
- **进入匹配排序**：硬条件和关键身份/索引检查已通过；仍需展示全部风险缺口，不称无风险。

高 IF 和匹配评分不能抵消排除/暂缓项。一般预警不是全国统一禁投，结合用户用途和单位要求给出理由。
