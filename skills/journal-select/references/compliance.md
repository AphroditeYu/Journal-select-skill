# 投稿合规与政策变化

对每本深入候选，先读具体期刊作者指南，再按链接核对出版商及适用资助方政策。不能以出版商的一般允许推翻期刊的特别限制；条款冲突无法解释时标为待编辑部澄清，未经授权不代发邮件。

## 将作者实际使用映射到条款

| 项目 | 需要核对 | 作者准备动作 |
|---|---|---|
| AI 文献梳理/构思/结构/写作/翻译 | 各用途是否允许、披露例外、人工核验要求、披露位置与内容 | 记录工具/版本或使用时间、目的和涉及部分，逐项核验引用与论断；不虚构已执行的核验 |
| AI 数据分析/代码/研究方法 | 方法可复现要求、参数、版本、验证方式 | 在方法部分如实描述，准备代码、日志或补充材料 |
| 图表 | 区分解释图、数据可视化、原始实验图、图文摘要、封面；核对 AI 边界、图注、授权和原图 | 保留真实数据与可复现步骤、原始图文件和许可；不能把一种图的允许推广到其他类型 |
| 数据/代码汇交 | 强制或鼓励、存储库、可用性声明、访问权限、匿名审稿链接 | 准备元数据、README、存储计划和声明；涉及隐私/知情同意时核对受控访问与例外，不建议违法公开 |
| 伦理与研究报告 | 按研究类型核对伦理批准、知情同意、注册、报告清单 | 列出现有与缺失材料；不能补造批准或倒填注册时间 |
| 作者与利益声明 | 贡献、署名、资助、利益冲突及 ORCID 等 | 核对作者真实贡献和期刊要求 |
| 格式和文章类型 | 字数、图表、补充材料、匿名化；综述是否须邀请 | 输出具体待办，不承诺改为短文就降低费用或提高录用率 |
| 预印本/版权/OA | 预印本兼容性、许可、存储和资助要求 | 核对实际期刊及作者协议，不能套用其他期刊规则 |

状态分为“已满足 / 需准备 / 与现状冲突 / 待核实 / 不适用”。作者没有提供材料时，不得标已满足。

## 变化记录

每条变化写：发布主体与适用范围、旧文日期、现行文日期/生效日期、具体差异、对这篇稿件的影响、来源。只有现行文本时写“现行要求，变化时间未核实”。

新旧条款为当前任务实时查询，不写死允许范围。检索时特别关注：
- [Elsevier AI 政策](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals)：用途、人工责任、披露及不同图像类型的细则。
- [Nature Portfolio AI 政策](https://www.nature.com/nature-portfolio/editorial-policies/ai)：现行适用框架与期刊个别要求。
- 其他出版商：从期刊主页进入官方政策，而不是转述前两家的规则。

JCR 计算规则属于评价政策，不是作者投稿格式要求。若比较不同年份的 IF，核对当年 Reference Guide/官方变更公告，说明口径变化可能影响可比性，不把指标变化全部归因于期刊质量变化。

例如 [Clarivate 2025 JCR 公告](https://ir.clarivate.com/news-events/press-releases/news-details/2025/Clarivate-Unveils-the-2025-Journal-Citation-Reports/default.aspx) 是有日期的历史变更证据；实际使用时仍检查当前版本。Skill 不把“2025 改动”包装成今年刚发生的新规。
