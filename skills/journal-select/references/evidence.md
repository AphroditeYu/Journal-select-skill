# 核验与证据记录

## 来源对应关系

| 事实 | 优先来源 | 必须区分 |
|---|---|---|
| 刊名、ISSN、收录类别与状态 | 数据库运营方官方记录；Web of Science Master Journal List、Scopus Sources | SCIE/SSCI/ESCI；有效覆盖年份；期刊被收录与单篇已检索 |
| JIF、排名、分区 | 相应年份的 JCR；相应版本的分区表 | 指标年份与发布年份；JCR 与中科院分区；大类与小类 |
| 中文核心/CSSCI/CSCD | 相应目录发布机构的官方目录 | 正式/扩展/来源集刊等类别；目录版本与单位适用版本 |
| 单位认可、报销、毕业要求 | 用户单位正式文件或书面确认 | 适用人群、入学/聘用年份、认定时点；不能用其他单位文件替代 |
| 费用与减免 | 期刊官方费用页、出版商协议页、机构图书馆 | 强制/可选 OA；投稿费、APC、超页/彩图、税费；减免资格 |
| 时间 | 官方指标页、近期论文的收稿/接收日期 | 首轮决定、外审后决定、接收、上线、检索；样本偏差 |
| 投稿与 AI/数据/伦理政策 | 具体期刊作者指南、出版商政策、适用资助方要求 | 特刊差异、文章类型差异、生效日期与范围 |
| 预警与限制 | 名单发布方、单位正式限制目录 | 预警不等于所有单位禁投；未列入不等于无风险 |
| 匹配程度 | scope、近期真实论文、作者指南 | 标题相似不等于方法、贡献与读者匹配 |

起始入口仅用于导航，每次仍须验证目标页面：
- Web of Science: https://mjl.clarivate.com/
- Scopus: https://www.scopus.com/sources
- JCR: https://jcr.clarivate.com/
- 中科院期刊分区表: https://www.fenqubiao.com/
- 国际期刊预警名单: https://earlywarning.fenqubiao.com/
- DOAJ: https://doaj.org/
- Think. Check. Submit.: https://thinkchecksubmit.org/

不得把 DOAJ、COPE、影响因子或任一单项标识当成无风险担保。

## 最小证据记录

每条影响决定的动态事实保留：

`期刊及 ISSN | 事实 | 值/条件 | 官方 URL/文件名及页码 | 核验日期 | 指标年份/生效日期 | 状态 | 限制`

状态用“官方已核验”“用户提供，尚未独立核验”“间接线索”“未核实”“来源冲突”。只有事实本身有充分官方证据，才能标为官方已核验；不能因为官网存在就核准官网未证明的内容。

如果来源冲突，报告双方时间和范围；按事实主管来源处理，例如收录以数据库为主、费用以实际适用的官方收费条款为主、单位认可以单位为主。无法消解则保留待确认，不能挑较有利的说法。

## 时效与差异比较

每次正式推荐重查关键动态事实；最终投稿前再次复核。旧报告可复用论文画像，但不能直接沿用费用、收录和政策结论。

“检索到的最新版本”不一定是“实际最新版本”。不得从抓取日期、搜索结果发布时间或年份关键词推断文件生效日期。

声称“改了哪里”须有可比的新旧文本；旧版可来自官方历史公告或有明确日期的官方文档。区分新要求、措辞澄清、执行范围变化与仅页面更新。旧版不可得时仅报告现行要求。

## 时间与费用的表达

费用保留原币种；换算时给出汇率来源和日期，且注明估算。没有减免确认，不把可能减免计入确定预算。

用已发表论文日期估算周期时注明样本数、时间范围和仅包含已接收稿件的局限，不能推算全部投稿的录用率。数据不足则写未知。
